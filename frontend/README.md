# LifeLink — Frontend Client

The frontend client for **LifeLink**, built with React 18, Vite, React Router v6, and modern CSS architecture.

---

## 🚀 Key Features

- **Public Experience:** High-converting landing page with blood donation awareness, live camps list, and direct emergency call to action.
- **Donor & User Experience:** Real-time request broadcast, donor mode toggle, interactive compatibility matrix, and history tracking.
- **Hospital Management:** Medical triage for emergency requisitions, linked blood bank dispatch, and delivery confirmations.
- **Blood Bank Management:** Real-time blood group inventory tracking, incoming hospital request pipeline, and camp scheduling.
- **NGO Coordination:** Community responses, blood donation drive management, and volunteer outreach.
- **Admin Dashboard:** Institutional KYC verification, user oversight, visual analytics, and exportable audit reports.

---

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **React Router v6**
- **Lucide Icons**
- **CSS3 Design System & Glassmorphism**
- **Leaflet & OpenStreetMap** for interactive location picking and geocoding

---

## 💻 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
> Client runs on: `http://localhost:5173`

### 3. Build for Production
```bash
npm run build
```
